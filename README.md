Welcome to Biomass Calulator Tool Software!

How to run the program?
1) Clone or download the repo.
2) Chose an IDE (Visual Studio Code) and open the folder (make sure you extract if you downladed the .zip).
3) Use the terminal and enter the command: pip install -r .\requirements.txt     (This will ensure all the libraries used to make this application will be installed)
4) Once the libraries are installed, enter > python main.py
